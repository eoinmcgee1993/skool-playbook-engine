# Architecture

The engine converts an authorised source bundle into an executable master playbook.

## Pipeline

1. Extract actionable concepts.
2. Classify by topic and business function.
3. Deduplicate equivalent knowledge.
4. Connect related concepts.
5. Identify missing implementation detail.
6. Expand gaps with clearly labelled additions.
7. Verify time-sensitive and tool-specific claims.
8. Curate into an executable playbook.
9. Publish versioned artefacts.

## Labels

- SOURCE: directly supported by supplied course material.
- EXPANSION: added implementation detail.
- UPDATE: newer platform/tool information.
- OPERATOR: practical execution guidance.

The engine must preserve provenance through every transformation.
